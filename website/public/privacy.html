Privasi

Halaman ini menjelaskan data yang digunakan website Nawam dan batasannya. Kebijakan berlaku untuk website ini; layanan pihak ketiga memiliki kebijakan tersendiri.

Website tanpa akun

Website tidak menyediakan registrasi, login, formulir pengumpulan data, iklan, atau analytics. Tidak ada cookie aplikasi maupun penyimpanan preferensi pengunjung yang sengaja dibuat oleh kode website ini.

Hosting dan unduhan

Halaman, font, dan gambar dilayani melalui Firebase Hosting. Paket aplikasi dan source diunduh melalui GitHub Releases; kebijakan privasi GitHub berlaku untuk permintaan tersebut. Penyedia infrastruktur dapat memproses data teknis seperti alamat IP, waktu permintaan, user-agent, serta log keamanan dan operasional. Lihat kebijakan privasi Google.

Clipboard

Tombol “Salin checksum” hanya menulis checksum SHA-256 ke clipboard saat Anda menekannya. Website tidak membaca isi clipboard Anda.

Tautan eksternal

Tautan dokumentasi, source, dan developer dapat membuka layanan di luar website Nawam. Kebijakan privasi layanan tujuan berlaku setelah Anda mengunjunginya.

Aplikasi desktop

Website tidak dapat melihat drive, ISO, atau isi USB Anda. Nawam memproses drive dan image secara lokal. Komponen boot tertentu dapat memerlukan unduhan jaringan; update aplikasi otomatis belum tersedia.

Pengaturan Nawam disimpan dalam registry khusus aplikasi atau nawam.ini pada mode portable. Log berisi informasi teknis yang dapat mencakup nama drive dan path file. Periksa serta hapus informasi pribadi sebelum membagikan log.

Hubungi developer

Informasi pengembang tersedia di shanna.id. Website tidak meminta password, token, atau akses ke drive Anda.
