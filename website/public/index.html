SIAPKAN LANGKAH BERIKUTNYA

Media yang tepat.
Untuk tujuan Anda.

INSTALLATION MEDIA

Mulai dengan instalasi yang baru.

Gunakan ISO Windows dari sumber resmi untuk menyiapkan USB instalasi. Pilih target boot yang sesuai dengan firmware komputer tujuan.

  • Image Windows dipindai sebelum digunakan
  • GPT untuk perangkat UEFI yang sesuai
  • Opsi mengikuti versi dan isi image Windows
INSTALL / LIVE ENVIRONMENT

Bawa lingkungan Linux Anda.

Buat media dari ISO distribusi pilihan. Ketersediaan mode ISO, DD, dan persistence bergantung pada struktur serta dukungan image.

  • Dukungan image Linux bootable
  • UEFI atau BIOS sesuai bootloader image
  • Komponen boot tambahan dapat memerlukan internet
NON-BOOTABLE MEDIA

Kembalikan USB menjadi ruang penyimpanan.

Pilih mode non-bootable untuk memformat perangkat. Tentukan sistem berkas, label volume, dan ukuran klaster yang tersedia untuk drive Anda.

  • Pilihan FAT32, NTFS, exFAT, dan lainnya sesuai perangkat
  • Quick format dan opsi pemeriksaan blok
  • Seluruh data pada target dapat terhapus

02 / DARI ISO KE USB

Empat langkah.
Satu tujuan yang jelas.

Siapkan file ISO tepercaya dan USB dengan kapasitas yang cukup. Cadangkan data USB sebelum melanjutkan.

  1. 01

    Hubungkan USB

    Jalankan Nawam, lalu cocokkan nama dan kapasitas perangkat. Jangan memilih drive hanya berdasarkan hurufnya.

  2. 02

    Pilih file ISO

    Klik PILIH, cari image Windows atau Linux Anda, lalu tunggu pemindaian image selesai.

  3. 03

    Periksa pengaturan

    Pastikan skema partisi, target sistem, dan sistem berkas sesuai komputer tujuan. Pertahankan nilai bawaan jika sudah sesuai.

  4. 04

    Mulai & tunggu

    Klik MULAI hanya setelah yakin. Baca konfirmasi penghapusan dan tunggu status selesai sebelum melepas USB.

!
Periksa drive dua kali. Data USB akan terhapus.

Pembuatan media bootable dan format merupakan operasi destructive. Cadangkan data penting. Jangan cabut USB atau matikan komputer saat proses berlangsung.

SEBELUM ANDA MULAI

Pertanyaan yang
sering muncul.

Tidak perlu menebak sebelum menyentuh data penting.

Apakah Nawam gratis?

Ya. Nawam merupakan perangkat lunak bebas di bawah GPL versi 3 atau yang lebih baru. Lihat lisensi dan attribution untuk detail basis source serta komponen pihak ketiga.

Apakah file dalam USB akan terhapus?

Ya. Format dan pembuatan media bootable dapat menghapus seluruh data pada perangkat tujuan. Cadangkan terlebih dahulu, verifikasi nama dan kapasitas drive, lalu baca setiap konfirmasi.

Harus pilih GPT atau MBR?

GPT umumnya digunakan untuk sistem UEFI modern, sedangkan MBR digunakan pada banyak sistem Legacy BIOS. Ikuti kebutuhan firmware dan image Anda. Jangan mengganti mode hanya karena dianggap lebih baru.

Apakah semua ISO bisa dibuat bootable?

Tidak. ISO harus memiliki metode boot yang didukung. Mengganti nama file menjadi .iso tidak membuatnya bootable. Gunakan image dari sumber resmi dan periksa checksum yang disediakan pembuatnya.

Mengapa harus dijalankan sebagai Administrator?

Nawam memerlukan akses tingkat rendah untuk mengelola partisi dan sistem berkas USB. Izin ini tidak membuat setiap tindakan aman secara otomatis—pilihan drive tetap harus diperiksa.

Bagaimana memakai mode portable?

Letakkan file kosong bernama nawam.ini di direktori yang sama dengan Nawam.exe. Preferensi kemudian disimpan di direktori tersebut. Gunakan lokasi yang dapat ditulis.

Kenapa tombol MULAI belum aktif?

Periksa apakah perangkat USB terdeteksi, image sudah dipilih dan selesai dipindai, serta pengaturan sesuai. Log aplikasi membantu menjelaskan masalah tanpa mencoba format berulang kali.

Mengapa Windows menampilkan Unknown publisher?

Build awal belum memiliki tanda tangan Authenticode. Metadata SHANNA Digital Systems bukan sertifikat digital. Unduh hanya dari sumber yang Anda percaya dan cocokkan SHA-256. Jangan menonaktifkan perlindungan Windows secara menyeluruh.

Apakah update otomatis sudah tersedia?

Belum. Nawam tidak menawarkan executable aplikasi lain sebagai pembaruan. Sampai sistem update khusus Nawam tersedia, gunakan unduhan manual di halaman ini.

Bagaimana melaporkan masalah?

Simpan log aplikasi, versi Nawam, versi Windows, dan detail ISO yang digunakan. Jangan sertakan data pribadi atau isi drive. Informasi developer tersedia melalui website SHANNA.
