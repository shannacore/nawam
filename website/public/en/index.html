02 / FROM ISO TO USB

Four steps.
One clear destination.

Prepare a trusted ISO file and a USB with enough capacity. Back up the USB data before continuing.

  1. 01

    Connect your USB

    Run Nawam, then check the device name and capacity. Do not choose a drive based only on its letter.

  2. 02

    Choose an ISO file

    Click SELECT, locate your Windows or Linux image, then wait for the image scan to finish.

  3. 03

    Review the settings

    Make sure the partition scheme, target system, and filesystem suit the destination computer. Keep the defaults if they already match.

  4. 04

    Start & wait

    Click START only when you are sure. Read the erase confirmation and wait for completion before removing the USB.

!
Check the drive twice. USB data will be erased.

Creating bootable media and formatting are destructive operations. Back up important data. Do not unplug the USB or shut down the computer while the operation is running.

BEFORE YOU BEGIN

Frequently asked
questions.

No need to guess before working with important data.

Is Nawam free?

Yes. Nawam is free software under GPL version 3 or later. See the license and attribution for details about the source base and third-party components.

Will files on my USB be erased?

Yes. Formatting and creating bootable media can erase all data on the target device. Back up first, verify the drive name and capacity, then read every confirmation.

Should I choose GPT or MBR?

GPT is commonly used for modern UEFI systems, while MBR is used on many Legacy BIOS systems. Follow your firmware and image requirements. Do not switch modes just because one seems newer.

Can every ISO be made bootable?

No. The ISO must have a supported boot method. Renaming a file to .iso does not make it bootable. Use images from official sources and check the checksum supplied by their creators.

Why does Nawam need Administrator access?

Nawam needs low-level access to manage USB partitions and filesystems. This permission does not automatically make every action safe—you still need to check the selected drive.

How do I use portable mode?

Place an empty file named nawam.ini in the same directory as Nawam.exe. Preferences are then saved in that directory. Choose a location you can write to.

Why is the START button disabled?

Check that the USB device is detected, an image is selected and fully scanned, and the settings are appropriate. The application log can help explain problems without repeated attempts to format.

Why does Windows show Unknown publisher?

The early build does not have an Authenticode signature. SHANNA Digital Systems metadata is not a digital certificate. Download only from sources you trust and compare the SHA-256 checksum. Do not disable Windows protection globally.

Are automatic updates available?

Not yet. Nawam does not offer another application's executable as an update. Until a dedicated Nawam update system is available, use the manual download on this page.

How do I report a problem?

Save the application log, Nawam version, Windows version, and details of the ISO used. Do not include personal data or drive contents. Developer information is available through the SHANNA website.
