License & Open Source

Nawam is a bootable USB creation utility for Windows. Developed by SHANNA Digital Systems. Nawam is based on the open-source Rufus project.

Upstream project & components

  • Rufus — the application base, GPL v3 or later.
  • wimlib — WIM image manipulation.
  • libcdio — ISO handling.
  • Syslinux, GNU GRUB, FreeDOS, ms-sys, and other components — boot media support.
  • UI redesign concept: Fahad Al-Riyami. Additional toolbar icons: Axialis Software, subject to the attribution terms in the source.

The complete list and each component's terms remain available in the source and the application's License & Open Source dialog. The Nawam USB logo is a new asset, not the Rufus logo.
