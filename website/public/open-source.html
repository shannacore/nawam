NAWAM / SHANNA DIGITAL SYSTEMS

Lisensi & Open Source

Nawam is a bootable USB creation utility for Windows. Developed by SHANNA Digital Systems. Nawam is based on the open-source Rufus project.

Project upstream & komponen

  • Rufus — basis aplikasi, GPL v3 atau lebih baru.
  • wimlib — manipulasi image WIM.
  • libcdio — penanganan ISO.
  • Syslinux, GNU GRUB, FreeDOS, ms-sys, dan komponen lainnya — dukungan media boot.
  • UI redesign concept: Fahad Al-Riyami. Additional toolbar icons: Axialis Software, sesuai ketentuan attribution pada source.

Tanpa jaminan

Perangkat lunak disediakan tanpa jaminan sebagaimana dijelaskan dalam GPL. Operasi format dapat menghapus data. Periksa target dan lakukan backup sebelum menggunakan aplikasi.
